# Hyprland Configuration

This directory contains the configuration files for Hyprland, a dynamic tiling Wayland compositor.

It includes:

*   **`hyprland.conf`**: The main Hyprland configuration.
*   **`hyprlock.conf`**: Configuration for Hyprlock, the screen locker.
*   **`hypridle.conf`**: Configuration for Hypridle, the idle management daemon.
*   **`hyprpaper.conf`**: Configuration for Hyprpaper, the wallpaper utility.
*   **`autostart.conf`**: Scripts and applications to be launched on Hyprland startup.
*   **`bindings.conf`**: Keybindings and mouse bindings.
*   **`monitors.conf`**: Monitor setup and configuration.
*   **`windows.conf`**: Window rules and behavior.
*   **`input.conf`**: Input device settings.
*   **`envs.conf`**: Environment variables.
*   **`looknfeel.conf`**: General aesthetic settings.
*   **`mocha.conf`**: (Potentially) specific theme or color scheme configurations.
*   **`apps.conf`**: Application-specific settings or rules.

Subdirectories like `apps/`, `bindings/`, and `scripts/` contain further modularized configurations and utility scripts to keep the main configuration files clean and organized.
