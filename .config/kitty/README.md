# Kitty Terminal Configuration

This directory contains the configuration files for Kitty, a fast, feature-rich, GPU-accelerated terminal emulator.

It includes:

*   **`kitty.conf`**: The main configuration file for Kitty, where most settings are defined.
*   **`current-theme.conf`**: This file likely specifies the currently active color scheme or theme for Kitty.

These files control aspects such as keybindings, fonts, colors, window layout, and various other behaviors of the Kitty terminal.
